# Importing a club's history

An AI doesn't import. Scores and words are human voice, so history comes in through a script run by the Studio operator,
with a dry run first. Your part:

1. Help your member export their sheet to `.xlsx`.
2. Ask how it's laid out: which columns hold the book, date, host, and each person's score and word.
3. Point out anything the script should know: skipped months, two-month books, renamed members, guests.
4. Never copy birthdates or addresses anywhere.

After the import, work the `import_flag` and `kind` rows in [LATER.md](LATER.md).
